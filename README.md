# 🤖 Discord-Bot

Un bot Discord simple et amusant, écrit en Python. Il propose des commandes pour taquiner vos amis, jouer de la musique et répondre de manière humoristique aux commandes mal formulées.

---

## 🚀 Fonctionnalités

- 🎵 Lecture de musique dans les salons vocaux
- 🗨️ Réponses humoristiques aux commandes incorrectes
- 🎮 Commandes personnalisées pour interagir avec les membres du serveur
